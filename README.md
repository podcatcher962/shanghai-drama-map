# 跟着电视剧游上海 ·《轧戏》取景地打卡指南

单文件在线版打卡指南：**4 大主题 · 11 处真实取景地**，地图打点 + 剧情注解 + 打卡提示，支持巡游讲解与飞线路線预览，每点可一键导航。

🔗 **在线地址**：https://podcatcher962.github.io/shanghai-drama-map/

## 使用方式

- 手机扫码（页面右上角「存入手机」）或直接打开上面的链接
- 左侧按主题筛选点位；右侧地图点标点查看剧情注解与打卡提示
- 「巡游模式」自动逐站飞行讲解；「飞线动画」预览路线走向
- 每个点位可「高德地图打开」「一键导航」或复制坐标（GCJ-02）

## 配置高德地图 Key（首次使用必须）

页面地图由高德地图 JS API 2.0 渲染，需要你自己的 Web 端 Key（免费）：

1. 打开 <https://lbs.amap.com/> 注册并登录
2. 控制台 → 应用管理 → 创建应用 → 添加 Key，平台类型选 **Web 服务（JS API）**
3. 下载本仓库的 `index.html`，用文本编辑器搜索 `AMAP_KEY`，按注释说明替换为你的 Key
4. 上传覆盖 / 本地双击打开即可；建议在控制台为 Key 绑定域名白名单防盗用

未配置 Key 时页面正常打开，列表、剧情注解、二维码与导航链接均可用，仅地图底图区域显示申请指引。
