## 使用

- **筛主题**：点列表上方徽标，左侧列表与右侧地图同步筛选
- **看详情**：点任意卡片，左下角弹出剧情注解、打卡提示与导航入口
- **一键导航**：卡片内「高德地图打开」或「一键导航」，自动唤起高德 App
- **存入手机**：顶栏「存入手机」生成二维码，扫码打开本在线版，可收藏 / 分享同好
- **版式**：顶栏「版式」在桌面双栏 / 手机抽屉式之间切换（自动按屏幕宽度）
