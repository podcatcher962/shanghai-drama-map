使用说明

看点位

左侧列表按 4 大主题分组，每张卡片含名称、地址、剧情注解与打卡提示；点卡片即在地图上定位并弹出详情。

筛主题

点列表上方的分组徽标（全部 / 落日江岸 / 入戏入口 / 市井弄堂 / 奔赴盛筵），左侧列表与右侧地图同步筛选。

巡游模式

地图右上角「巡游模式」：按当前顺序自动飞到每一处点位并弹出讲解，适合先云游一遍全线路；随时点「停止」或按 Esc 结束。（完整交互模式功能，需配置高德 Key，见「关于」）

飞线动画

「飞线动画」：把当前筛选的点位按顺序连成一条流动的金色飞线，预览路线走向与点位分布。（完整交互模式功能，需配置高德 Key，见「关于」）

存入手机

顶栏「存入手机」生成二维码：扫码打开在线版页面（建议在微信里「收藏」或添加到浮窗，出行时随时打开），页面内含全部点位与一键导航，也可把链接分享给同好。

坐标说明

页面使用高德地图坐标（GCJ-02，与腾讯地图同源，可直接互粘）。个别点位为片区级位置（如园区、桥梁），导航时请以点位名称为准。

地图说明

当前为免 Key 嵌入模式：地图由高德 URI 服务提供（11 处点位、缩放拖动、一键导航均可使用）。若地图上出现「移动端」浮层，点其右上角 × 关闭即可；偶发显示登录页时，点左上提示条上的 ⟳ 重新加载。配置高德 Key 后可启用巡游/飞线动画（方法见「关于」）。
